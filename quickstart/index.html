迁移成本几乎为零，改 base_url 和 api_key 两个值就行，其余业务代码一行不用动。

  1. 确认模型标识：先区分目标名 gpt-5.6 与已列出的 gpt-5.6-luna、gpt-5.6-sol、gpt-5.6-terra，再按实际可用条目选择模型别名。
  2. 选择用户分组：确认用户所在分组及倍率；default 分组倍率为 ×0.07353，其余分组以面板配置为准。
  3. 核对基准价格：从 https://api.openlux.ai/api/pricing 读取模型基准价格，并将基准价与用户分组倍率分开记录，不要把基准价直接当作最终价格。
  4. 发起接口请求：使用选定的模型标识和中转站实际提供的接口参数发起请求，模型能力、参数兼容性和返回格式以实际接口结果为准。
  5. 复核结果与计费：对照平台展示的计费明细核查模型名、请求结果和计费口径，并按基准价乘分组倍率复核金额；上线前保留请求记录，便于排查模型映射与链路问题。

from urllib.request import urlopen
import json

url = "https://api.openlux.ai/api/pricing"

with urlopen(url) as response:
    pricing = json.load(response)

print(json.dumps(pricing, ensure_ascii=False, indent=2))
